# Códigos de fábrica

Para cambiar el código propio (`20…`) por el código de barras que trae el envase.

1. *Costos y precios → Listas de proveedores → **Códigos de fábrica***.
2. Están los productos que todavía tienen el código propio.
3. Clic en **Escanear acá** de la primera fila.
4. Agarrar el producto y escanear el código del envase. El lector pasa solo a la fila de abajo.
5. El producto sale de la lista. El código viejo sigue sirviendo en la caja: no hace falta
   despegar etiquetas.

**El producto no trae código** (suelto, pesable, fraccionado): tocar **No tiene** en su fila.
Sale de la lista y conserva el código propio. Para deshacerlo: filtro «Marcados sin código de
fábrica» → **Volver**.

**Si avisa «ya es de otro producto»:** se escaneó el producto equivocado, o los dos son el mismo
producto (avisarle a quien administra productos: se unen con «Fusionar»).

Para buscar uno en particular: escribir el nombre arriba, en la búsqueda.

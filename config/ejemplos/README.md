# Capa `ejemplos` (solo laboratorio)

Datos **ficticios** para probar la herramienta y experimentar con el modelado de
productos. No representan decisiones del negocio ni se aplican a producción.

Los códigos de barras usan el prefijo `2` (rango de uso interno en GS1), que es una
de las opciones a evaluar para códigos internos (ver `docs/areas/codigos.md`).

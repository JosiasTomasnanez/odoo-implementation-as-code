# Datos

- Solo datos **ficticios o anonimizados** y plantillas de importación.
- Datos reales del cliente: nunca en git. Si hay que trabajarlos localmente, usar
  `data/privado/` (ignorado por git) o una ubicación fuera del repositorio.
- Los datos de configuración (categorías, listas, etc.) van en `config/`, no acá.
